WHAT THE ADB SCAN CHECKS
Third-party packages are read through Android's Package Manager. A risk score is based on signals such as overlay permission, accessibility services, install-package permission, boot persistence and ad/overlay-related strings in package metadata. These are signals only, not proof that an app is malicious.
Uninstall requires an explicit tap for each package. The app uses pm uninstall --user 0, so some preinstalled/system packages cannot be removed and may only be disabled by the device owner/manufacturer.
